# AURELIA — Live Demo

Static, **backend-free** demo of the AURELIA platform (Autonomous Unified
Reasoning Engine for Lifecycle Intelligent Architecture).

**▶ Live:** https://miorfaridhal.github.io/aurelia-demo/

- `/` — feature landing page
- `/app/` — the full React app running on **sample data** (no backend). The
  7-brain sprint-planning pipeline, dashboards, and prompt-transparency are all
  interactive; data is illustrative only.

This repo contains only the compiled demo. Source lives in the private
`aurelia` repository.
